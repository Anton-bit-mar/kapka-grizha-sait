# Капка грижа всеки ден

Статичен сайт за Петя, независим консултант на dōTERRA.

- `sait/` е готовият сайт. Качва се както е, например в Netlify, като формите работят чрез Netlify Forms.
- `generator/` е Python генераторът, от който се прави сайтът:
  - всички настройки (линкове, телефон, снимка, отзиви) са в `CONFIG`, най-горе в `build.py`;
  - продуктите и изрязаните снимки са в `danni/`;
  - новините са `.md` файлове в `danni/novini/`;
  - стиловете и рисунките са в `assets/`;
  - PDF наръчникът се прави от `narachnik/`.

## Повторно генериране

```
python3 generator/build.py generator/danni sait
```

За да се направи PDF наръчникът, са нужни Node.js и Playwright.

Текстовете не съдържат медицински твърдения и обещания за доходи. Пазете ги такива и при промени.
